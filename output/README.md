# Output（出力）

## 概要
このディレクトリは生成された物語の本文を保存します。

## ディレクトリ構成

### chapters/
各章の完成した本文を保存します。
- ファイル名形式: `chapter-01.md`, `chapter-02.md`, ...
- 各ファイルには完成した物語の本文が含まれます

## 使い方

### 物語を生成する
1. `characters/`, `settings/`, `plot/` などの設定を確認
2. プロットに従って物語を生成
3. `chapters/` ディレクトリに章ごとに保存

### ファイル命名規則
- 章番号を使用: `chapter-[番号].md`
- 例: `chapter-01.md`, `chapter-02.md`, `chapter-03.md`
- ゼロパディング推奨（章が10以上ある場合）

### 各章ファイルの構成例
```markdown
# 第X章: [章タイトル]

[本文...]

---

## メモ
- 登場キャラクター: [リスト]
- 登場場所: [リスト]
- 重要なイベント: [リスト]
- 伏線: [リスト]
```

## 注意事項
- キャラクター設定、場所設定、プロットとの整合性を確認
- 世界観のルールが守られているか確認
- テーマが適切に表現されているか確認
- 前後の章との繋がりを意識する
- 完成した章は定期的にバックアップする
