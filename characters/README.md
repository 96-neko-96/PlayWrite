# Characters（登場人物）

## 概要
このディレクトリは物語に登場するキャラクターの詳細プロフィールを管理します。

## 使い方

### 新しいキャラクターを追加する
1. `_template.md` をコピー
2. 適切なファイル名で保存（例: `主人公.md` または `character-01.md`）
3. テンプレートのすべての項目を埋める

### ファイル命名規則
- キャラクター名を使用: `[名前].md`（例: `太郎.md`）
- または番号を使用: `character-[番号].md`（例: `character-01.md`）
- 日本語・英語どちらも可

### 記入のポイント
- **基本情報**: キャラクターの基礎データ
- **外見**: 読者がイメージできる具体的な描写
- **性格**: 行動の一貫性を保つための性格設定
- **背景**: キャラクターの動機を裏付ける経歴
- **役割**: 物語におけるキャラクターの機能
- **人間関係**: 他のキャラクターとの関係性
- **能力と弱点**: キャラクターの限界を明確にする

## 注意事項
- 物語の進行に応じてキャラクター設定を更新してください
- 他のキャラクターとの関係性に矛盾がないか確認してください
- キャラクターの行動が設定した性格と一貫しているか注意してください
