# Settings（舞台・場所）

## 概要
このディレクトリは物語の舞台となる場所や環境の設定を管理します。

## 使い方

### 新しい場所を追加する
1. `_template.md` をコピー
2. 適切なファイル名で保存（例: `王都.md` または `setting-01.md`）
3. テンプレートのすべての項目を埋める

### ファイル命名規則
- 場所名を使用: `[場所名].md`（例: `王都.md`）
- または番号を使用: `setting-[番号].md`（例: `setting-01.md`）
- 日本語・英語どちらも可

### 記入のポイント
- **基本情報**: 場所のタイプと規模
- **物理的描写**: 読者がイメージできる具体的な描写
- **歴史**: その場所の成り立ち
- **文化**: 住民の生活様式や特徴
- **物語における役割**: なぜこの場所が重要か
- **雰囲気**: 場所が持つ印象や感情

### 場所のタイプ例
- 都市、村、町
- 建物（城、館、店など）
- 自然（森、山、海など）
- その他の特殊な場所

## 注意事項
- 場所の描写が物語内で一貫しているか確認してください
- 関連する他の場所との位置関係を明確にしてください
- その場所で起こる重要なイベントを記録してください
