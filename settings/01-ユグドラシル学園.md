# ユグドラシル学園

## 基本情報
- **名称**: ユグドラシル学園（ユグドラシルがくえん）
- **英名**: Yggdrasil Academy
- **種別**: 全寮制高等学園
- **所在地**: ユグドラシル大樹・上層部（高度250m付近）
- **創立**: 大崩壊後128年（約172年前）

---

## 概要

ユグドラシル大樹の上層部に位置する名門学園。全寮制で、樹上文明における最高峰の教育機関の一つ。学術都市として発展したユグドラシル大樹の象徴的存在。主に上層民と優秀な中層民の子弟が通う。

---

## 施設の詳細

### 位置と構造

**所在階層**:
- 高度250m付近（上層部）
- 樹の内部空洞を大規模改造
- 樹の外側にも校舎が張り出す

**占有面積**:
- 内部空洞: 約5万平方メートル
- 外部施設: 約2万平方メートル
- 総計: 7万平方メートルの広大なキャンパス

**構造図**:
```
        樹の外側
           │
    ┌──────────┐
    │ 天文台    │ (高度270m)
    └─────┬────┘
          │
    ┌──────────────────┐
    │   教室棟・研究棟    │ (高度260m)
    │   ┌────────┐     │
    │   │ 中央広場 │     │
    │   └────────┘     │
    └──────────────────┘
          │
    ┌──────────────────┐
    │   管理棟・図書館    │ (高度250m)
    │                      │
    └──────────────────┘
          │
    ┌──────────────────┐
    │   寮・食堂・体育館  │ (高度240m)
    └──────────────────┘
```

### 主要施設

#### 1. 教室棟
- 30の教室
- 各教室には大きな窓（外の景色が見える）
- 樹の半透明な壁を利用した自然光照明
- 黒板とチョーク（紙は貴重なためノートは再利用可能な石板も使用）

#### 2. 研究棟
- 生物学実験室
- 化学実験室
- 物理実験室
- 工学実験室
- 樹学研究室（樹そのものを研究する特殊な施設）

#### 3. 図書館
**規模**:
- 蔵書数: 約10万冊
- 旧文明の書籍も一部保存
- 樹上文明の学術書が中心

**特徴**:
- 樹の内壁を利用した5層構造
- 螺旋階段でアクセス
- 静寂な空間、勉強スペース豊富
- 司書は知識豊富で学生の相談に乗る

#### 4. 寮
**構成**:
- 男子寮: 600名収容
- 女子寮: 600名収容
- 1部屋2-4人の相部屋が基本
- 上級生や成績優秀者は個室

**設備**:
- 共同浴場
- 共同トイレ
- 談話室
- 自習室

#### 5. 食堂
- 収容人数: 500名
- 3食提供（朝・昼・夕）
- メニューは質素だが栄養バランスは良好
- 上層階にある教職員専用レストラン

#### 6. 体育館
- 室内競技場
- 垂直クライミング施設（樹の外壁を利用）
- トレーニングルーム

#### 7. 中央広場
- 学園の中心部にある開放空間
- 樹の自然光が降り注ぐ
- 学生の憩いの場
- 行事やイベントの会場

#### 8. 天文台
- 学園の最上部に位置
- 夜空の観測が可能
- 天文部の活動拠点
- ロマンチックなデートスポット

#### 9. 外部テラス
- 樹の外側に設置されたバルコニー
- 絶景を楽しめる
- 高所恐怖症の学生には厳しい

## 部活動・サークル

### 運動部
- **垂直登攀部**: 樹の外壁クライミング
- **グライダー部**: グライダー飛行
- **スカイボール部**: 空中球技
- **武道部**: 護身術と武術

### 文化部
- **天文部**: 星空観測
- **生物研究部**: 樹上生態系の研究
- **図書委員会**: 図書館運営補助
- **新聞部**: 学園新聞の発行
- **音楽部**: 樹の木管楽器の演奏
- **美術部**: 絵画・彫刻

### 非公式サークル
- **探検同好会**: 樹の未開拓部分を探検（半ば非公認）
- **旧文明研究会**: 失われた技術の研究
- **根元調査会**: 禁断の根元部への興味を持つ危険な集まり

## 学生の構成

### 階層別比率

- **天層民出身**: 10%（約120名）
- **上層民出身**: 60%（約720名）
- **中層民出身**: 28%（約336名）
- **下層民出身**: 2%（約24名、ほぼ全員が奨学生）

### 奨学金制度

- 成績優秀な中層民・下層民に学費免除の奨学金
- 競争率は非常に高い
- 奨学生は学内でプレッシャーを感じることも

## 学園の文化・伝統

### 年間行事

**春**:
- 入学式
- 新入生歓迎会
- 樹誕祭（樹の誕生を祝う）

**夏**:
- 中間試験
- 夏季休暇（1週間）
- グライダー大会

**秋**:
- 学園祭（文化祭）
- 体育祭（垂直競技など）
- 収穫祭

**冬**:
- 期末試験
- 冬季休暇（2週間）
- 星空祭（樹冠部で星空を見る）

### 伝統・噂

**伝統**:
- 卒業生は樹に自分の名前を刻む（樹は自己修復するので数年で消える）
- 天文台で告白すると成就するジンクス
- 3年間無遅刻無欠席だと学園長から特別表彰

**七不思議**:
1. 図書館の奥に旧文明の禁書がある
2. 夜中に樹の声が聞こえる
3. 地下（根元部）に続く隠し通路がある
4. 幽霊が出る教室がある
5. 樹が選んだ特別な学生がいる
6. 昔、根元部に降りた学生が行方不明になった
7. 天文台から何かが見える特別な夜がある

## 規則

### 主な校則

1. **門限厳守**: 外出時は申請必要、夜間外出禁止
2. **階層移動制限**: 許可なく下層部へ行くことは禁止
3. **根元部立入禁止**: 絶対的な禁止事項
4. **授業中の私語禁止**
5. **制服着用義務**

### 罰則

- 軽度: 清掃作業
- 中度: 停学
- 重度: 退学

## 物語における重要性

ユグドラシル学園は主人公たちの日常の舞台であり、友情、恋愛、成長、葛藤が繰り広げられる場所。階層社会の縮図でもあり、さまざまな出自の学生たちが交流することで、社会の矛盾や不公平に気づくきっかけとなる。

学園の「七不思議」や禁断の根元部への好奇心が、物語の冒険要素を駆動する。
