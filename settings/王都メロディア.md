# 王都メロディア

## 基本情報
- **正式名称**: 王都メロディア
- **タイプ**: 首都、大都市
- **所在地**: 王国の中央に位置
- **規模**: 人口約5万人の大都市

## 物理的描写

### 外観
- 高い城壁に囲まれた壮麗な都市
- 中心に王城がそびえ立つ
- 白亜の建物が立ち並び、尖塔が空を突く
- 大通りには噴水や彫像が配置され、美しく整備されている

### 内部構造
- **王城**: 都の中心にそびえる荘厳な城
- **音楽の殿堂**: 王城近くにある巨大な音楽ホール、千人を収容できる
- **大広場**: 王城前の広場、祭りや公式行事が行われる
- **商業区**: 高級品から日用品まで揃う賑やかな市場
- **住宅区**: 貴族の邸宅街と庶民の居住区
- **芸術家地区**: 音楽家、画家、詩人などが集まる地区
- **宿屋街**: 外来者のための宿泊施設が集まる

### 地理・環境
- 平野部に計画的に建設された都市
- 大きな川が都を横切り、美しい橋がかかる
- 周囲を肥沃な農地が取り囲む
- 街道が四方に延び、王国各地へ繋がる

### 気候・天候
- 温暖な気候
- 四季がはっきりしている
- 春は花祭り、秋は音楽祭が開催される

## 歴史・由来
- 王国建国時に築かれた古都
- 「メロディア」の名は「音楽の都」を意味する古語から
- 歴代の王が音楽と芸術を愛し、保護してきた
- 数百年の歴史を持つ音楽の殿堂は王国の誇り
- 年に一度の音楽祭は伝統行事として継承されている

## 文化・特徴

### 住民・人口
- 人口約5万人
- 貴族、商人、職人、芸術家など多様な階層
- 各地から才能ある音楽家が集まる
- 教養が高く、芸術への理解が深い

### 文化的特徴
- **音楽祭**: 年に一度、秋に開催される盛大な祭り
- **音楽家ギルド**: 優れた音楽家が所属する名誉ある組織
- **音楽の殿堂**: 毎週のように演奏会が開かれる
- **王立音楽学院**: 才能ある若者が音楽を学ぶ
- 音楽と芸術が日常生活に深く根付いている

### 経済・産業
- 王国の経済の中心
- 高級楽器の製作と取引
- 芸術品、書籍の出版
- 各地からの交易品が集まる
- 音楽家への支援や貴族の後援文化

### 政治・統治
- 国王が統治する王国の首都
- 音楽と芸術を重んじる開明的な王
- 貴族と市民議会が協力して都市を運営
- 治安は良好で、衛兵が巡回
