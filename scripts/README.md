# Scripts（スクリプト）

## 概要
このディレクトリは物語生成や管理を支援するスクリプトを保存します。

## 使い方

### スクリプトの種類

#### 生成スクリプト
物語の本文を自動生成するスクリプト
- プロットに基づいて章を生成
- キャラクター設定や場所設定を参照
- 出力を `output/chapters/` に保存

#### チェックスクリプト
設定の一貫性をチェックするスクリプト
- キャラクター設定の矛盾チェック
- 場所設定の整合性チェック
- 世界観ルールの違反チェック
- プロットとテーマの整合性チェック

#### ユーティリティスクリプト
その他の補助的なスクリプト
- テンプレートからファイル生成
- ファイル名の一括変換
- 統計情報の収集
- バックアップの作成

## スクリプトの追加

### 新しいスクリプトを追加する
1. このディレクトリに適切な名前でスクリプトファイルを作成
2. スクリプトの目的と使い方をコメントで記述
3. 必要に応じてREADMEを更新

### 推奨するスクリプト言語
- Python: 汎用的なスクリプト処理
- Shell: シンプルなファイル操作
- JavaScript/Node.js: JSON処理やAPI連携

## 注意事項
- スクリプトは既存のファイルを上書きする前に確認を求める
- エラーハンドリングを適切に実装する
- スクリプトの実行には適切な権限が必要な場合がある
- 重要なファイルは必ずバックアップを取る
