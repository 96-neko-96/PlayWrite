# PlayWrite - 物語創作管理システム

## 概要
PlayWriteは物語創作のための体系的な管理システムです。キャラクター、設定、プロット、世界観などすべての物語要素を構造化して管理し、一貫性のある作品を作成することを目的としています。

## 特徴
- **体系的な管理**: すべての物語要素を整理して保存
- **テンプレート駆動**: 一貫したフォーマットで設定を記録
- **一貫性の確保**: 物語内の矛盾を防ぐ構造
- **拡張可能**: 必要に応じて要素を追加可能

## 使い方

### 1. プロジェクトのセットアップ

#### ステップ1: ルールの確認
まず `STORY_PROJECT_RULES.md` を読んで、プロジェクトの構造とルールを理解してください。

#### ステップ2: 基本設定の作成
以下の順序で物語の基本設定を作成していきます：

1. **テーマの定義** (`themes/main-themes.md`)
   - 物語で伝えたいメッセージやテーマを明確にする

2. **世界観の構築** (`worldbuilding/`)
   - 物語の舞台となる世界のルールや設定を定義
   - `_template.md` をコピーして各設定要素を作成

3. **場所の設定** (`settings/`)
   - 物語に登場する場所を設定
   - `_template.md` をコピーして各場所を作成

4. **キャラクターの作成** (`characters/`)
   - 登場人物のプロフィールを作成
   - `_template.md` をコピーして各キャラクターを作成

5. **プロットの構築** (`plot/`)
   - `outline.md` で全体のあらすじを書く
   - `chapter-structure.md` で章立てを決める
   - 必要に応じて個別の章プロット (`chapter-XX-plot.md`) を作成

### 2. 物語の生成

すべての設定が整ったら、以下の手順で物語を生成します：

1. プロットファイルを確認
2. キャラクター、場所、世界観の設定を確認
3. テーマを念頭に置きながら執筆
4. 完成した章を `output/chapters/` に保存

### 3. 設定の更新と管理

物語の進行に応じて設定を更新します：

- 新しいキャラクターが登場したら `characters/` に追加
- 新しい場所が登場したら `settings/` に追加
- 物語の展開に応じてプロットを更新
- 一貫性チェックを定期的に実施

## テンプレートの使い方

各ディレクトリには `_template.md` ファイルがあります。新しい要素を追加する際は：

1. テンプレートファイルをコピー
2. 適切なファイル名で保存
3. すべての項目を埋める

### 例: 新しいキャラクターの追加

```bash
# charactersディレクトリに移動
cd characters/

# テンプレートをコピー
cp _template.md 主人公.md

# エディタで開いて編集
# すべての項目を埋める
```

## 一貫性チェック

物語を書く際は、以下の点に注意して一貫性を保ちましょう：

### キャラクターの一貫性
- [ ] キャラクターの行動が性格設定と矛盾していないか
- [ ] キャラクターの能力がルール内で使われているか
- [ ] 人間関係が設定と一致しているか

### 世界観の一貫性
- [ ] 世界のルールが守られているか
- [ ] 魔法や技術の使用が設定に従っているか
- [ ] 歴史的背景と矛盾していないか

### プロットの一貫性
- [ ] 伏線が適切に回収されているか
- [ ] 時系列が正しいか
- [ ] 因果関係が論理的か

### テーマの一貫性
- [ ] 物語全体を通してテーマが表現されているか
- [ ] キャラクターの成長がテーマと関連しているか

## ファイル命名規則

### キャラクター
- `[名前].md`（例: `太郎.md`, `田中花子.md`）
- `character-[番号].md`（例: `character-01.md`）

### 場所
- `[場所名].md`（例: `王都.md`, `魔法学院.md`）
- `setting-[番号].md`（例: `setting-01.md`）

### 世界観設定
- `[設定要素名].md`（例: `魔法体系.md`, `歴史.md`）

### プロット
- `chapter-[番号]-plot.md`（例: `chapter-01-plot.md`）

### 出力
- `chapter-[番号].md`（例: `chapter-01.md`, `chapter-02.md`）

## ヒントとベストプラクティス

### 計画を立てる
物語を書き始める前に、しっかりと設定を作り込みましょう。事前の準備が物語の質を向上させます。

### 小さく始める
最初からすべてを完璧にする必要はありません。最小限の設定から始めて、必要に応じて拡張していきましょう。

### 定期的な見直し
設定ファイルは定期的に見直し、物語の進行に応じて更新しましょう。

### バックアップ
重要なファイルは定期的にバックアップを取りましょう。

### 柔軟性を持つ
設定はガイドラインです。物語を書く過程で変更が必要になることもあります。柔軟に対応しましょう。

## トラブルシューティング

### 設定が矛盾している
1. 関連するすべての設定ファイルを確認
2. 矛盾する部分を特定
3. どちらかを修正、または両方を調整

### プロットが行き詰まった
1. `outline.md` に戻って全体の流れを確認
2. テーマを再確認
3. キャラクターの動機を見直す

### キャラクターが動かない
1. キャラクターの目標と動機を確認
2. 性格設定を見直す
3. 必要に応じてキャラクター設定を更新

## プロジェクト例

### 「平成くんと令和ちゃん」

このリポジトリには、実際のプロジェクト例として「平成くんと令和ちゃん」という短編小説が含まれています。

**概要**：
平成時代と令和時代を代表する二人のキャラクターが、会社のカフェスペースで偶然出会い、世代間ギャップに驚きながらも、対話を通じて互いの良さを認め合う心温まるコメディ。

**作品情報**：
- **ジャンル**: コメディ / 現代劇 / 会話劇
- **総文字数**: 約13,000字（拡張版）
- **シーン構成**: 5シーン
- **テーマ**: 世代間ギャップと相互理解

**登場人物**：
- **平成くん（平成誠）**: 35歳の中堅営業マン。真面目で忠実、アナログ派
- **令和ちゃん（令和彩花）**: 22歳の新入社員。効率重視、デジタルネイティブ

**シーン構成**：
- シーン1（導入）: 約2,500字 - 二人の出会いと疲労感の描写
- シーン2（価値観の違い）: 約3,500字 - 働き方とコミュニケーション手段の対立
- シーン3（共通点の発見）: 約3,400字 - 推し活を通じた相互理解のターニングポイント
- シーン4（ギャップコメディ）: 約1,900字 - 再びのギャップを笑いに変える
- シーン5（新しい関係性）: 約1,700字 - 互いを認め合う心温まる結末

**完成作品**: [output/平成くんと令和ちゃん.md](output/平成くんと令和ちゃん.md)

このプロジェクトは、PlayWriteの構造を活用して、キャラクター設定、テーマ設定、プロット構築、シーン構成を体系的に管理しながら作成されました。各シーンを丁寧に描写し、登場人物の内面や世代間ギャップをリアルに表現しています。
