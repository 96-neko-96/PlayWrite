# Themes（テーマ）

## 概要
このディレクトリは物語のテーマやメッセージを管理します。

## ファイル構成

### main-themes.md
物語の中心となるテーマを記述します。
- 主題（メインテーマ）
- 副題（サブテーマ）
- 象徴的要素
- テーマの表現方法

## 使い方

### テーマを定義する
1. `main-themes.md` を開く
2. 物語で伝えたいメッセージやテーマを明確にする
3. キャラクターやプロットでどのようにテーマを表現するか計画する

### テーマ設定のポイント
- **明確性**: テーマは明確で焦点が絞られている
- **一貫性**: 物語全体を通してテーマが一貫している
- **表現**: 説教的でなく、物語を通して自然に伝わる
- **深さ**: 表面的でなく、読者が考えさせられる深みがある
- **普遍性**: 読者が共感できる普遍的な要素がある

### テーマの例
- 愛と犠牲
- 正義と復讐
- 成長と自己発見
- 権力と責任
- 希望と絶望
- 友情と裏切り
- 自由と束縛

## 注意事項
- テーマはキャラクターの行動や成長に反映させる
- プロットの展開はテーマを強化する
- 複数のテーマがある場合、それらの関係性を明確にする
- テーマを押し付けず、読者に解釈の余地を残す
