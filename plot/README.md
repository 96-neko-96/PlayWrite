# Plot（プロット・構成）

## 概要
このディレクトリは物語の筋書きと構成を管理します。

## ファイル構成

### outline.md
物語全体のあらすじを記述します。
- 物語の始まり
- 中盤の展開
- クライマックス
- 結末

### chapter-structure.md
章立て構成を管理します。
- 各章のタイトル
- 各章の目的
- 各章の主要な出来事

### chapter-XX-plot.md
個別の章の詳細プロットを記述します。
- ファイル名形式: `chapter-01-plot.md`, `chapter-02-plot.md`, ...
- 各章のシーン構成
- 登場するキャラクターと場所
- 伏線や重要な描写

## 使い方

### 物語を企画する
1. まず `outline.md` で全体のあらすじを書く
2. `chapter-structure.md` で章立てを決める
3. 各章の詳細を `chapter-XX-plot.md` として作成

### プロット作成のポイント
- 物語の目的とテーマを明確にする
- 起承転結を意識する
- キャラクターの成長を計画する
- 伏線と回収を記録する
- 各章の役割を明確にする

## 注意事項
- キャラクター設定、場所設定との整合性を保つ
- テーマファイルで定義したテーマを反映させる
- 物語の進行に応じて定期的に見直す
