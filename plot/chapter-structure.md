# 章立て構成：『黄泉の手招き』

## 全体構成
- **予定総章数**: 4章 + プロローグ + エピローグ
- **推定総文字数**: 80,000〜100,000文字（中編小説）
- **1章あたりの平均文字数**: 15,000〜20,000文字

---

## 章一覧

### プロローグ: 穢れの器

- **位置付け**: 序章（短い導入）
- **目的**: 物語の雰囲気を確立し、読者を引き込む
- **主要な出来事**:
  - 鷺沼の日常と内面の苦しみを簡潔に描写
  - 異常な依頼の電話を受ける
  - 「何かが変わる」予感
- **登場キャラクター**: 鷺沼晶
- **登場場所**: 鷺沼のアパート（都市部）
- **伏線**:
  - 鷺沼の手の火傷の痕（トラウマの暗示）
  - 自己破壊的な傾向（危険な依頼を受ける）
  - 「自分は生きている価値があるのか」という問い
- **文字数目安**: 2,000〜3,000文字
- **トーン**: 暗く、抑圧された、孤独
- **重要なイメージ**: 殺風景な部屋、消えない炎の記憶、鳴り響く電話

### 第1章: 霧に覆われた村

- **位置付け**: 導入・世界観の提示
- **目的**:
  - 天結の里の異様な雰囲気を確立
  - 浄師・御清の登場
  - 最初の異形の変死体を提示し、ホラーを開始
- **主要な出来事**:
  - 里への到着（吊り橋、霧、白い村）
  - 浄師との対面と依頼の詳細
  - 穢れ小屋への滞在
  - 夜の里の探索
  - 最初の変死体「溶け落ちた蝋燭」の発見
  - トラウマのフラッシュバック
- **登場キャラクター**:
  - 鷺沼晶（視点人物）
  - 浄師・御清（初登場）
  - 浄補たち
  - 里の住民（背景）
- **登場場所**:
  - 吊り橋と石段
  - 天結の里（全景）
  - 浄師の館
  - 穢れ小屋
  - 住民の家屋（変死体の現場）
  - 浄水盤（遠景）
- **伏線**:
  - 御清の顔の火傷
  - 「汝は何かを探しているのか」という問い
  - 里に色がないこと
  - 住民の無表情と感情の欠如
  - 浄水盤の不気味な存在感
  - 里の水の微かな薬草の匂い
  - 墓地を見かけないこと（何気ない描写）
- **文字数目安**: 18,000〜20,000文字
- **トーン**: 不安、違和感、美しさと不気味さの共存
- **重要なシーン**:
  1. **吊り橋を渡る**：霧の中、一歩ずつ進む鷺沼。下は深い谷。外の世界との断絶を象徴
  2. **御清との初対面**：彼女の目に映る「何か」を感じ取る鷺沼。彼女は鷺沼を見抜いている
  3. **「溶け落ちた蝋燭」の発見**：詳細なボディホラー。鷺沼のトラウマがフラッシュバック。炎の幻視

### 第2章: 異形との対峙

- **位置付け**: 恐怖の深化・ミステリの展開
- **目的**:
  - ボディホラーを段階的にエスカレート
  - 鷺沼の心理的崩壊を描く
  - 水捌けの儀を目撃させ、物語の核心へ
- **主要な出来事**:
  - 最初の遺体の清掃作業（数日間）
  - 二体目「皮膚の祭壇」の発見と清掃
  - 里の日常生活の観察
  - 浄水盤への接近と警告
  - 御清との会話（心理的操作の開始）
  - 水捌けの儀の目撃（物語のミッドポイント）
- **登場キャラクター**:
  - 鷺沼晶
  - 浄師・御清
  - 浄補たち
  - 里の住民（儀式参加者）
  - 穢れ人（儀式の犠牲者）
- **登場場所**:
  - 変死体の現場（2箇所）
  - 里の各所（観察）
  - 浄水盤（近距離）
  - 浄師の館（御清との会話）
  - 穢れ小屋（鷺沼の居室）
- **伏線**:
  - 住民の微妙な恐怖（表には出さないが、彼らも怯えている）
  - 子供たちの目の奥の空虚さ
  - 御清の言葉：「人は皆、穢れを抱えている」
  - 浄水盤の縁の爪痕と血痕
  - 鷺沼が儀式に「魅惑」を感じること
- **伏線の回収**:
  - 鷺沼のトラウマの詳細が明らかになる
- **文字数目安**: 20,000〜22,000文字
- **トーン**: 恐怖の増大、嫌悪と魅惑の混在、心理的不安定
- **重要なシーン**:
  1. **「溶け落ちた蝋燭」の清掃**：溶解した肉体の詳細描写。鷺沼の手が震える。吐き気
  2. **「皮膚の祭壇」の発見**：白いキノコ、胞子の噴出。さらにグロテスクな光景
  3. **子供との遭遇**：笑わない子供。「大人になったら、私も浄化されるの？」という無邪気な問い
  4. **御清との茶会**：彼女の穏やかな声。しかし問いは鋭い。「汝は、何から逃れようとしているのか」
  5. **水捌けの儀の目撃**：最も重要なシーン。祝詞、清水の服用、激しい嘔吐。鷺沼は恐怖と、奇妙な魅惑を同時に感じる

### 第3章: 狂気の構造

- **位置付け**: 真相解明・心理的崩壊
- **目的**:
  - 里の秘密をすべて明らかにする
  - 鷺沼の心理が里の論理に取り込まれる過程を描く
  - 最終章への準備（鷺沼の幽閉）
- **主要な出来事**:
  - 三体目「燃える胎児」の清掃
  - 浄師の館への侵入
  - 「浄化の記録」の発見
  - 清水の正体の理解
  - 墓地が無いことの確認
  - 御清の部分的な告白（愛した男性の話）
  - 鷺沼の自己認識の崩壊
  - 穢れ人としての認定
  - 幽閉期間（3日間）
- **登場キャラクター**:
  - 鷺沼晶
  - 浄師・御清
  - 浄補たち
  - 里の住民
  - （記録の中の）過去の犠牲者たち
- **登場場所**:
  - 変死体の現場（三体目）
  - 浄師の館（記録の間、調合の間）
  - 里の各所（墓地探し）
  - 穢れ小屋（幽閉）
  - 浄水盤（遠景、鷺沼の視線）
- **伏線の回収**:
  - 御清の火傷の理由（愛した男性を殺した時）
  - 里に墓地がない理由（遺体は浄水盤に沈められる）
  - 清水の匂いの正体（毒キノコと薬草の混合物）
  - 鷺沼の自己破壊願望の理由（トラウマ）
  - 御清が鷺沼を「見抜いていた」理由（彼女も同じ罪悪感を持っていたから）
- **新しい伏線**:
  - 鷺沼が儀式を「拒絶しない」予兆
  - 御清の涙（わずかに。彼女の内面の疲れ）
- **文字数目安**: 22,000〜25,000文字
- **トーン**: 緊張、恐怖、絶望、そして奇妙な諦念
- **重要なシーン**:
  1. **「燃える胎児」の発見**：最も異様な変死体。鷺沼は職業的冷静さを完全に失う
  2. **記録の間での発見**：数百名の名前。「浄化後死亡」の文字。鷺沼の震え
  3. **御清との対峙**：「これは殺人だ！」と叫ぶ鷺沼。しかし御清は静かに自分の過去を語る
  4. **御清の告白**：「私も、かつては汝と同じだった。愛する者がいた」彼女の目に涙はない。しかし声は震えている
  5. **自室での独白**：鷺沼は混乱する。「自分は本当に穢れているのか？」「もし浄化が本当なら...」
  6. **穢れ人の宣告**：住民たちが集まる。御清の宣言。鷺沼は抵抗しない
  7. **幽閉期間**：3日間の静寂。鷺沼の内面の独白。恐怖と、奇妙な安堵

### 第4章: 黄泉への手招き

- **位置付け**: クライマックス・結末
- **目的**:
  - 水捌けの儀を内側から描く
  - 鷺沼の最終的な選択とその帰結
  - 物語のテーマを結実させる
  - 救いのない結末を提示
- **主要な出来事**:
  - 儀式の夜
  - 浄水盤への移動
  - 祝詞と清水の服用
  - 幻覚の地獄（トラウマとの対峙）
  - 浄化の幻想と真実の認識
  - 結末（エンディングA or Bのどちらか）
- **登場キャラクター**:
  - 鷺沼晶（主役）
  - 浄師・御清
  - 浄補たち
  - 里の住民（見学者）
  - （幻覚の中の）過去の犠牲者
- **登場場所**:
  - 穢れ小屋（出発点）
  - 浄水盤（メインステージ）
  - （幻覚の中の）過去の火事現場
  - （幻覚の中の）未知の空間（黄泉？）
- **伏線の回収**:
  - すべての伏線が収束
  - 鷺沼の選択の必然性
  - 御清の涙の意味
  - 「黄泉の手招き」の意味
- **文字数目安**: 20,000〜25,000文字
- **トーン**: 緊張の極致、恐怖、悲しみ、そして虚無
- **重要なシーン**:
  1. **儀式の始まり**：月が最も高い夜。松明の灯り。住民たちの無表情
  2. **浄水盤への縛り付け**：白い縄。足が虚空に垂れ下がる。井戸の底を見つめる鷺沼
  3. **祝詞**：「穢れは器を厭い...」単調な響き。住民の唱和。時間が歪む
  4. **清水の服用**：鷺沼は自ら飲む。苦味。効果の開始
  5. **幻覚の地獄**：炎の中の建物。助けを求める声。「お前は助ける気がなかった」という非難
  6. **浄化の幻想**：嘔吐。黄色い粘液。一瞬の解放感。「救われる」という錯覚
  7. **真実の瞬間**：「これは救いではない。これは死だ」痙攣、呼吸困難
  8. **最後の対話**：幻覚の中で、犠牲者と再び対面。「お前は、自分を許さなかった」優しい微笑み
  9. **結末**：エンディングAまたはB（推奨はB：狂気の継承）
  10. **御清の反応**：鷺沼の変死体（または変容した姿）を見つめる。一粒の涙。そしてすぐに言う：「彼は浄化された」

### エピローグ: 続く招き

- **位置付け**: 結末後の余韻
- **目的**:
  - 物語が「終わっていない」ことを示す
  - 里の狂気は続くことを暗示
  - 読者に不安と問いを残す
- **主要な出来事**:
  - 数年後
  - 新しい外部者が里を訪れる（または訪れようとしている）
  - 浄水盤は静かに存在し続ける
  - 「黄泉の手招き」は続く
- **登場キャラクター**:
  - 新しい訪問者（名前なし、描写は最小限）
  - （エンディングBの場合）浄師となった鷺沼（または次の浄師）
- **登場場所**:
  - 吊り橋（遠景）
  - 天結の里（遠景）
  - 浄水盤（最後のイメージ）
- **文字数目安**: 1,000〜2,000文字
- **トーン**: 静か、しかし不穏。終わりなき循環
- **最後のイメージ**:
  - 浄水盤の底から伸びる無数の手（幻視または現実）
  - 「おいで」と招いている
  - 黄泉への手招き

## 執筆の順序（推奨）

物語を効果的に書くための推奨順序：

1. **第2章を最初に書く**
   - 理由：異形の描写、ボディホラーの確立。物語の「味」を決定
   - 鷺沼の心理描写の練習
   - 儀式のシーンを詳細に描くことで、物語の核心を確立

2. **第4章を次に書く**
   - 理由：結末を明確にすることで、全体の方向性が定まる
   - どのエンディングを選ぶか決定
   - クライマックスの描写を完成させる

3. **第1章を書く**
   - 理由：結末を知った上で導入を書くことで、効果的な伏線を配置できる
   - 里の第一印象を、結末と対比させて描く

4. **第3章を書く**
   - 理由：第1、2、4章を書いた後なら、真相解明のバランスが取りやすい
   - 情報の開示の仕方を調整できる

5. **プロローグとエピローグを最後に書く**
   - 理由：全体を書き終えてから、最も適切な枠組みを決定できる

## シーンごとの視点と時制

### 視点
- **全編を通して**：鷺沼晶の一人称視点（「私」または「俺」）
- 推奨は「私」（より内省的、文学的）
- または三人称視点だが鷺沼の内面に密着（「鷺沼は...と思った」）

### 時制
- **基本**：過去形（「〜だった」「〜した」）
- **回想シーン**：過去完了形または時制を明示（「あの時...」）
- **幻覚シーン**：現在形を混ぜることで臨場感（「炎が迫ってくる」）

効果的な章の開始と終了のために：

### プロローグ
- **冒頭**: 「夢から覚めると、部屋には焦げ臭い匂いが満ちていた。」（炎の記憶）

- **冒頭**: 「記録には、三百十七の名前が記されていた。」（真相の発見）

### 第4章
- **冒頭**: 「月が最も高い夜、私は浄水盤の縁に座っていた。」（儀式の開始）

## メモ

### 執筆時の重要な注意点

1. **ペース配分**
   - 第1章：ゆっくりと不安を醸成
   - 第2章：恐怖を段階的にエスカレート
   - 第3章：情報を一気に開示、しかし混乱させる
