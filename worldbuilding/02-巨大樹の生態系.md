# 巨大樹の生態系

## 基本情報
- **名称**: 巨大樹（きょだいじゅ） / ワールドツリー / 世界樹
- **カテゴリー**: 生態系・環境設定
- **重要度**: 最高（人類の生存基盤）

---

## 概要

大崩壊後に出現した巨大な樹木。高さ200-500メートル、幹の直径100-300メートルに及ぶ。内部は複雑な空洞構造を持ち、数万人から数十万人の人間が生活できる。毒ガス完全耐性を持ち、人類最後の生存圏となっている。

---

## 物理的特性

### サイズと構造

**平均的な巨大樹のスペック**:
- 高さ: 300-400メートル（最大級は500メートル超）
- 幹の直径: 150-250メートル
- 根の広がり: 地下500メートル以上（推定）
- 枝の広がり: 半径100-200メートル
- 推定重量: 数百万トン

**構造の特徴**:
```
┌─────────────────────────────────────┐
│         樹冠部（300-500m）            │ ← 上層居住区・展望台
│    ／＼＿＿＿／＼                      │
│   ／    ┌────┐   ＼                 │
├─────────────────────────────────────┤

│    │    │    │    │                 │
│    │ ┌──┴──┐ │                     │
├─────────────────────────────────────┤
│         中層部（100-200m）            │ ← 商業区・中流層居住区
│    │ │      │ │                     │
│    │ │ ┌──┐ │ │                    │
├─────────────────────────────────────┤
```

### 内部構造

**自然形成された居住空間**:
- 樹の内部は自然に大小の空洞を形成
- 空洞同士は通路状の空間で接続
- まるで「最初から人間を受け入れるように設計された」構造
- 空間の広さ: 小部屋（10㎡）から大空洞（10,000㎡超）まで様々

**壁面の性質**:
- 木質だが異常に堅牢（鋼鉄の5倍の強度）
- 表面は滑らかで、加工が可能（ただし高度な技術が必要）
- 自己修復能力あり（小さな傷は数日で修復）
- 断熱性・防音性に優れる

**光の供給**:
- 樹皮の一部が半透明で自然光を取り込む
- 「光壁」と呼ばれる発光する内壁が存在
- 光壁は昼夜サイクルに連動して明るさが変化
- 人工照明を補助的に使用

## 生態学的特性

### 樹そのものの生態

**栄養摂取**:
- 根は地下深く（毒ガス層を貫通）まで伸びる
- 何を栄養源としているかは不明
- 水は地下水脈から吸い上げている
- 葉は光合成を行う（通常の樹木と同様）

**成長と寿命**:
- 出現から3ヶ月で現在の高さまで成長
- その後の成長速度は極めて緩やか（年1-2センチ程度）
- 300年経過しても衰える兆候なし
- 寿命は不明（数千年、数万年、あるいは永遠？）

**繁殖**:
- これまで種子や花が確認されたことはない
- 新しい巨大樹が自然発生した記録もない
- 現存する樹は大崩壊時の3,200本のみ

**損傷と修復**:
- 小規模な損傷: 数日で完全修復
- 中規模な損傷: 数週間で修復
- 大規模な損傷: 記録なし（そもそも傷つけることが困難）

### 樹上の生態系

**植物**:
- 樹の枝や内壁に苔類、蔦類、小型植物が自生
- 人間による農業も可能（土を持ち込んで栽培）
- 樹上農園では野菜、果物、穀物を栽培
- 収穫量は限られており、貴重な食料源

**動物**:
- 鳥類: 大崩壊を生き延びた種が樹上に生息
- 昆虫類: 豊富に存在（一部は新種）
- 小型哺乳類: リス、コウモリなどが樹の外側に生息
- 大型動物: ほぼ絶滅（一部の樹で家畜として飼育）

**微生物**:
- 樹内部に独自の微生物生態系が形成
- 人間の生活に有益な分解者としての役割
- 一部は発酵食品の製造に利用

**食物連鎖**:
```
光（太陽・光壁）
    ↓
植物（苔・蔦・農作物）
    ↓
昆虫・小動物
    ↓
鳥類・人間
    ↓
分解者（微生物）
    ↓
樹の栄養？（未解明）
```

## 人間社会との関わり

### 居住空間としての利用

**階層別の利用**:

1. **樹冠部（300-500m）**
   - 最も安全で眺望の良い場所
   - 超富裕層の居住区
   - 展望施設・リゾート
   - 人口密度: 低い

2. **上層部（200-300m）**
   - 富裕層・上流階級の居住区
   - 学園・研究施設
   - 官公庁・行政機関
   - 人口密度: やや低い

3. **中層部（100-200m）**
   - 中流層の居住区
   - 商業施設・市場
   - 中小工場
   - 人口密度: 中程度

4. **下層部（50-100m）**
   - 下流層・労働者の居住区
   - 大規模工場
   - 廃棄物処理施設
   - 人口密度: 高い

5. **根元部（0-50m）**
   - 毒ガス層に接近
   - 立入禁止区域
   - 犯罪者の潜伏場所という噂
   - 人口密度: ほぼゼロ（違法居住者のみ）

### 改造と建築

**内装**:
- 自然の空洞をそのまま部屋として利用
- 壁面に棚や家具を設置
- 床面を平坦に加工
- 間仕切りの設置

**外装**:
- 樹の外側にバルコニーやテラスを設置
- 枝の間に建物を建築（空中建築）
- 橋や通路で樹同士を接続
- 飛行船の発着場

**インフラ**:
- 水道: 樹が吸い上げる地下水を利用
- 電気: 風力・太陽光発電、一部で燃料発電
- 通信: 光ファイバーケーブルを樹内に敷設
- エレベーター: 人力・蒸気・電力駆動の様々な方式

## 樹の個体差

世界中の巨大樹にはそれぞれ個性がある。

### サイズによる分類

- **大樹級**: 高さ400m以上、人口20万人以上を擁する大都市
- **中樹級**: 高さ250-400m、人口5-20万人の中都市
- **小樹級**: 高さ200-250m、人口1-5万人の小都市
- **孤樹**: 高さ200m未満、人口1万人未満の小規模コミュニティ

### 有名な巨大樹（例）

1. **ユグドラシル大樹** (本作の舞台)
   - 高さ: 420メートル
   - 人口: 約15万人
   - 特徴: 学術都市として発展、複数の学園が存在
   - 所在地: 旧日本列島中部（推定）

2. **アトラス巨樹**
   - 高さ: 510メートル（世界最大級）
   - 人口: 約30万人
   - 特徴: 商業の中心地、最大の交易拠点

3. **セドナ樹**
   - 高さ: 380メートル
   - 人口: 約18万人
   - 特徴: 宗教都市、多数の寺院が存在

## 樹に関する信仰と文化

### 樹信仰

- 樹を神聖視する宗教が複数存在
- 「樹は意思を持つ」と信じる人々
- 樹に祈りを捧げる習慣
- 樹の誕生日を祝う祭り

### タブーと掟

- 樹を傷つける行為は重罪
- 樹の内壁に落書きすることは禁忌
- 樹の液体（樹液）を無駄にしてはならない
- 樹に感謝を捧げる習慣

### 樹にまつわる言い伝え

- 「樹は人類を救うために現れた救世主」
- 「樹は生きていて、良い人間と悪い人間を見分けている」
- 「樹が怒ると内部空間が縮小する」（科学的根拠なし）
- 「樹は実は全てつながっている」（一部の学者が支持）

## 物語における重要性

巨大樹は単なる舞台ではなく、人類の生存基盤であり、社会構造を決定する存在である。樹の階層構造は社会階層を象徴し、樹との関わり方が登場人物の価値観を形成する。

主人公たちが通う学園は上層部にあり、彼らは比較的恵まれた環境で育っているが、下層部の現実や、樹の外の世界への好奇心が物語を動かす。
