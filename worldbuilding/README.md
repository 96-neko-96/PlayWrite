# Worldbuilding（世界観設定）

## 概要
このディレクトリは物語の世界観や設定の詳細を管理します。

## 使い方

### 新しい設定要素を追加する
1. `_template.md` をコピー
2. 設定要素名でファイルを保存（例: `魔法体系.md`, `歴史.md`）
3. テンプレートのすべての項目を埋める

### 管理する設定要素の例
- **魔法体系**: 魔法の仕組み、ルール、制約
- **技術レベル**: 文明の発展度、利用可能な技術
- **歴史**: 世界の歴史、重要な出来事
- **文化**: 社会制度、習慣、信仰
- **経済**: 通貨、貿易、経済システム
- **政治**: 国家体制、権力構造
- **種族**: 存在する種族とその特性
- **言語**: 言語体系、方言
- **その他**: 物語に必要な独自の設定

### ファイル命名規則
- 設定要素名を使用: `[要素名].md`（例: `魔法体系.md`）
- 日本語・英語どちらも可
- わかりやすく具体的な名前をつける

### 記入のポイント
- **概要**: 設定要素の簡潔な説明
- **詳細**: 仕組みやルールの詳細
- **制約**: 何ができて何ができないか
- **歴史**: その設定がどう生まれたか
- **影響**: 物語や社会への影響
- **使用例**: 物語での具体的な使い方

## 注意事項
- 世界観のルールは一貫性を保つ
- 設定要素同士の関連性を明確にする
- 物語で実際に使用する設定に焦点を当てる
- 複雑すぎる設定は避け、読者が理解できる範囲にする
