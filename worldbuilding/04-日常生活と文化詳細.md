# 日常生活と文化詳細

## 基本情報
- **名称**: 樹上文明の日常生活
- **カテゴリー**: 文化・生活設定
- **重要度**: 高（キャラクターの行動リアリティを支える）

---

## 食生活

### 主食

**樹上で栽培される穀物**:
- **スカイライス**: 樹上農園で栽培される稲の変異種
  - 収穫量は旧文明の米の60%程度
  - 貴重で、主に上層・中層民が食べる
  - 価格: 1kg 50 SM

- **エアウィート**: 空中栽培に適した小麦の改良種
  - パンやパスタの原料
  - 比較的安価で、全階層で消費
  - 価格: 1kg 20 SM

- **ツリーコーン**: 樹の枝に寄生する穀物
  - 下層民の主食
  - 栄養価は低いが、大量に収穫できる
  - 価格: 1kg 5 SM

**代替食品**:
- **樹実パン**: 樹の実を粉にして作るパン
- **昆虫粉**: タンパク質源として昆虫を粉末化
- **藻類ケーキ**: 樹内水槽で培養した藻を固めたもの

### 副菜と調味料

**野菜**:
- 垂直農園で栽培: トマト、レタス、ホウレンソウの改良種
- 樹上キノコ: 樹内部に自生、重要なタンパク源
- 空中芋: 宙吊り栽培される芋類

**タンパク質**:
- **養殖魚**: 樹内の水槽で飼育（高価）
- **昆虫**: コオロギ、イモムシなどを養殖
- **鳥肉**: 野鳥の狩猟または飼育（超高級品）
- **樹汁豆腐**: 樹液から作る豆腐状の食品

**調味料**:
- **樹塩**: 樹液を煮詰めて作る塩
- **スカイソース**: 発酵調味料
- **樹蜜**: 樹に寄生する昆虫が作る蜂蜜様物質

### 階層別の食事例

**上層民の一日**:
- 朝食: スカイライスのお粥、焼き魚、樹上野菜のサラダ、樹汁豆腐の味噌汁
- 昼食: エアウィートのパン、鶏肉のグリル、温野菜、果物
- 夕食: スカイライス、刺身、天ぷら、スープ、デザート
- 月の食費: 1人あたり 500-800 SM

**中層民の一日**:
- 朝食: エアウィートのパン、樹汁豆腐、昆虫粉入りスープ
- 昼食: ツリーコーンの雑穀飯、野菜炒め、漬物
- 夕食: 雑穀飯、焼き魚（週1回）、樹上野菜、味噌汁
- 月の食費: 1人あたり 200-300 SM

**下層民の一日**:
- 朝食: ツリーコーンの粥、塩漬け
- 昼食: ツリーコーンのパン、昆虫の佃煮
- 夕食: ツリーコーンの飯、藻類のスープ、漬物
- 月の食費: 1人あたり 80-120 SM

### 食文化

**外食産業**:
- **上層**: 高級レストラン、カフェ、ティーサロン
- **中層**: 大衆食堂、麺類専門店、居酒屋
- **下層**: 立ち食い屋台、配給食堂

**食のタブー**:
- 樹の生きた部分を食べることは厳禁
- 鳥を無駄に殺すことは罪
- 食べ物を残すことは罪（下層ほど厳格）

**特別な料理**:
- **樹誕祭の御膳**: 年に一度の豪華な食事
- **空揚げ**: 鳥肉を揚げた最高級料理
- **星空団子**: 満月の夜に食べる伝統菓子

## 住居と生活空間

### 階層別の住居

**上層民の住居**:
```
【間取り例】
┌─────────────────────┐
│  バルコニー（空中庭園）      │
├─────────────────────┤
│  リビング（30㎡）           │
│  ├─ 寝室（15㎡）× 3       │
│  ├─ 書斎（10㎡）          │
│  ├─ バスルーム（8㎡）      │
│  └─ キッチン（12㎡）       │
└─────────────────────┘
総面積: 100-150㎡
家賃: 月 1,500-3,000 SM
```

**特徴**:
- 天井が高い（3-4m）
- 半透明な壁から自然光
- 個人用エレベーター付き
- 温水・冷房完備
- 防音性が高い

**中層民の住居**:
```
【間取り例】
┌─────────────┐
│  共用廊下         │
├─────────────┤
│  リビング兼寝室  │
│  （20㎡）        │
│  ├─ 子供部屋   │
│  │   （8㎡）    │
│  ├─ 台所       │
│  │   （5㎡）    │
│  └─ 水回り     │
│      （3㎡）    │
└─────────────┘
総面積: 35-50㎡
家賃: 月 300-600 SM
```

**特徴**:
- 天井2.5m程度
- 光壁による採光
- 共用エレベーター
- 最低限の設備
- 隣室の音が聞こえる

**下層民の住居**:
```
【間取り例】
┌──────────┐
│  狭い通路    │
├──────────┤
│  部屋        │
│  （12㎡）    │
│  ├─ 簡易台所│
│  └─ 共用WC │
└──────────┘
総面積: 12-20㎡
家賃: 月 80-150 SM
```

**特徴**:
- 天井2m程度、圧迫感
- 薄暗い（照明不足）
- 階段のみ（エレベーターなし）
- 水道は共用
- 家族4-5人で一部屋も珍しくない

### 家具と生活用品

**共通の家具**:
- **樹材家具**: 樹の廃材で作る（最も一般的）
- **折りたたみ式**: 空間節約のため多用
- **組み込み式**: 壁面収納が主流

**階層による違い**:
- 上層: 旧文明のアンティーク家具を所有することも
- 中層: 実用本位のシンプルな家具
- 下層: 最低限、自作も多い

### 照明

**光源の種類**:
1. **自然光**: 半透明壁からの採光（無料）
2. **光壁**: 樹が発する生物発光（無料だが上層のみ）
3. **電灯**: 電力消費（電気代が高い）
4. **ランプ**: 油やロウソク（安価だが暗い）

**電気代**:
- 上層: 月 200-500 SM（定額制）
- 中層: 月 100-200 SM（従量制）
- 下層: 月 50-100 SM（共用の最低限）

## 服装とファッション

### 基本的な素材

**天然素材**:
- **樹綿**: 樹の種子から取れる綿
  - 柔らかく吸湿性が良い
  - やや高価

- **昆虫糸**: 特定の昆虫が作る糸
  - 絹のような光沢
  - 非常に高価（上層民のみ）

- **樹皮布**: 樹皮を加工した布
  - 丈夫だが固い
  - 下層民の日常着

**合成素材**:
- **リサイクル繊維**: 旧文明の衣類を再利用
- **昆虫殻繊維**: 昆虫の殻を糸状に加工

### 階層別の服装

**上層民**:
- 男性: スーツ、ブレザー、シルクシャツ
- 女性: ドレス、ワンピース、スカート
- 学生: 制服（ブレザー型、品質が良い）
- 色: 明るい色、白、青、緑
- アクセサリー: 金属製（旧文明の遺物）

**中層民**:
- 男性: シャツ、チノパン、カジュアル
- 女性: ブラウス、スカート/パンツ
- 学生: 制服（シンプル）
- 色: 落ち着いた色、茶、灰、紺
- アクセサリー: 木製、最小限

**下層民**:
- 男性: 作業着、ジャケット
- 女性: シンプルなワンピース、パンツ
- 学生: 制服なし（私服）
- 色: 暗い色、黒、茶、グレー
- アクセサリー: ほぼなし

### 髪型

**流行**:
- 上層女性: 長髪、巻き髪、アップスタイル
- 上層男性: 短髪、整髪
- 下層: 実用本位、短く切る

### 化粧

- 上層女性: 化粧が一般的
- 中層女性: 控えめな化粧
- 下層女性: ほとんどしない（化粧品が高価）

## 一日の生活リズム

### 時刻の表し方

**樹上時刻**:
- 1日24時間制（旧文明を継承）
- 光壁の明るさで時間を感知
- 公共時計が各所に設置

**生活時間**:
```
05:00 - 光壁が明るくなり始める
06:00 - 起床（一般的）
07:00 - 朝食
08:00 - 仕事・学校開始
12:00 - 昼食
13:00 - 午後の仕事・授業
17:00 - 仕事終了（上層・中層）
19:00 - 夕食
20:00 - 仕事終了（下層、長時間労働）
21:00 - 自由時間
22:00 - 就寝準備
23:00 - 消灯（光壁が暗くなる）
```

### 休日

**週休制**:
- 上層・中層: 週1-2日休み
- 下層: 週1日（あるいは隔週）

**祝日**:
年間約12日
- 樹誕祭（春）
- 収穫祭（秋）
- 星空祭（夏至）
- 新年祭
など

## 娯楽と余暇

### 階層別の娯楽

**上層民**:
- **観劇**: 樹上劇場でのミュージカル、演劇
- **音楽会**: オーケストラ、室内楽
- **読書**: 旧文明の本は貴重
- **スポーツ観戦**: スカイボール、グライダーレース
- **社交パーティー**: 夜会、舞踏会
- **旅行**: 他の樹への観光

**中層民**:
- **街の祭り**: 各地区の催し
- **居酒屋**: 仲間と飲む
- **簡易スポーツ**: 樹内クライミング
- **ラジオ**: 音楽・ドラマ番組
- **ボードゲーム**: 将棋、チェス様のゲーム

**下層民**:
- **賭け事**: 違法だが横行
- **路上パフォーマンス**: 大道芸、音楽
- **井戸端会議**: コミュニティの交流
- **子どもの遊び**: 鬼ごっこ、かくれんぼ

### スポーツ

**人気スポーツ**:

1. **スカイボール**
   - 空中ネットを使った球技
   - 3対3のチーム戦
   - 上中層で人気

2. **ツリークライミング**
   - 樹の外壁を登る競技
   - スピードと技術を競う
   - 全階層で人気

3. **グライダー競技**
   - グライダーでの曲芸飛行
   - 富裕層の娯楽
   - 観戦は無料で人気

4. **垂直マラソン**
   - 樹の階段を駆け上がる
   - 年1回の大会
   - 全階層参加可能

### 芸術

**音楽**:
- **樹笛**: 樹の空洞を利用した笛
- **弦楽器**: 昆虫の糸を使った楽器
- **打楽器**: 樹材の太鼓

**絵画**:
- **空景画**: 空や雲を描く
- **樹肖像**: 樹そのものを描く
- **旧世界想像画**: 地表の世界を想像で描く

**彫刻**:
- 樹材彫刻が主流
- 上層民の間で人気

## 人生の節目

### 誕生

**出産**:
- 病院出産（上層・中層）
- 自宅出産（下層）
- 出生率: 1家族あたり平均2-3人

**命名**:
- 樹や空に関連する名前が人気
- 上層は伝統的な名前を好む

**祝い**:
- 誕生日は家族でささやかに祝う
- 上層は盛大なパーティー

### 成人

**成人の儀式**:
- 15歳で「樹上礼」という成人式
- 樹の最上部に登る試練
- 合格すると「成人」と認められる

### 結婚

**婚姻制度**:
- 一夫一婦制が基本
- 同じ階層同士の結婚が多い
- 階層を超えた結婚は稀（特に上層は難しい）

**結婚式**:
- 上層: 盛大な式典、披露宴
- 中層: 身内のみの質素な式
- 下層: 届け出のみ、式なしも多い

**結婚年齢**:
- 平均: 男性25歳、女性22歳
- 下層はやや早い傾向

### 死

**平均寿命**:
- 上層: 75-80歳
- 中層: 65-70歳
- 下層: 50-55歳

**葬儀**:
- **樹葬**: 樹の特定の場所に遺体を安置
  - 樹が分解・吸収してくれる
  - 「樹と一つになる」という考え

- **空葬**: 遺体を空に放つ（富裕層のみ）
  - 非常に高価
  - 魂が空に昇るとされる

## 教育詳細

### 初等教育（6-12歳）

**カリキュラム**:
- 読み書き算数
- 樹学基礎
- 歴史（大崩壊について）
- 道徳（樹への感謝）
- 体育（樹内移動訓練）

**環境**:
- 上層: 少人数制、個別指導
- 下層: 大人数、設備不足

### 中等教育（12-15歳）

**カリキュラム**:
- 専門分野の基礎（理系・文系）
- 職業訓練の開始
- 社会システムの学習

**進路**:
- 上層: ほぼ全員が学園へ進学
- 中層: 約半数が学園へ、半数は就職
- 下層: ほとんどが就職（奨学金で数%が進学）

### 学園教育（15-18歳）

詳細は [ユグドラシル学園](../settings/01-ユグドラシル学園.md) を参照。

## 年中行事

### 樹誕祭（春・3月頃）

**内容**:
- 樹の誕生を祝う最大の祭り
- 全階層で祝日
- 樹に感謝の祈りを捧げる
- 特別な料理を作る
- 花火大会

### 収穫祭（秋・10月頃）

**内容**:
- 農作物の収穫を感謝
- 市場が特別に開かれる
- 農民への感謝を表す
- ダンスと音楽

### 星空祭（夏至・6月頃）

**内容**:
- 一年で最も星がきれいに見える夜
- 樹冠部での観察会
- 願い事をする習慣
- カップルのデートスポット

### 新年祭（1月1日）

**内容**:
- 新しい年の始まりを祝う
- 家族で過ごす
- 初日の出を見る（樹冠部）
- 新年の抱負を述べる

## コミュニケーションと人間関係

### 階層間の壁

**物理的な壁**:
- 階層間の移動は許可制
- 検問所が存在
- 身分証明書の提示が必要

**心理的な壁**:
- 階層が違うと「別世界の人」という認識
- 下層民は上層民に引け目を感じる
- 上層民は下層を「知らない」「関わらない」

### 言葉遣い

**階層による違い**:
- 上層: 丁寧語、敬語の使い分け
- 中層: 普通の話し言葉
- 下層: 荒い言葉遣いも多い

**方言**:
- 樹ごとに微妙な訛りがある
- 同じ樹内でも階層で違う

### 友情と恋愛

**友人関係**:
- 同階層の友人が大半
- 学園が異階層交流の場となる（稀な例）

**恋愛**:
- 同階層での恋愛が「普通」
- 階層を超えた恋は困難
  - 家族の反対
  - 社会的偏見
  - 経済的格差

## 犯罪と治安

### 主な犯罪

**上層部**:
- 横領、汚職
- 麻薬（希少）
- 不正取引

**中層部**:
- 窃盗
- 詐欺
- 密輸

**下層部**:
- 暴力犯罪
- 強盗
- 賭博（違法）

### 刑罰

- 軽犯罪: 罰金
- 中程度: 禁固刑、強制労働
- 重罪: 根元部への追放（事実上の死刑）
- 最重罪: 空からの投下（極めて稀）

## 物語における重要性

これらの詳細な生活設定は、登場人物たちの日常をリアルに描くために不可欠です。

- ソラたちの上層での恵まれた生活
- アキラの下層での苦しい現実
- 階層間の具体的な格差
- 若者たちの価値観の形成

これら全てが、物語に深みとリアリティを与えます。
