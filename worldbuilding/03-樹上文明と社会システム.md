# 樹上文明と社会システム

## 基本情報
- **名称**: 樹上文明（じゅじょうぶんめい） / スカイボーン文明
- **カテゴリー**: 社会・文化設定
- **重要度**: 高

---

## 概要

大崩壊から300年が経過し、人類は巨大樹の中で新しい文明を築き上げた。垂直方向に発展した社会構造、限られた資源の配分システム、樹と樹を結ぶ交易ネットワーク、そして新しい価値観と文化が形成されている。

---

## 社会構造

### 階層社会

樹上文明は明確な階層構造を持つ。物理的な高さが社会的地位と強く結びついている。

**階層区分**:

1. **天層民（てんそうみん）** - 樹冠部居住者
   - 人口比: 約5%
   - 特徴: 超富裕層、政治家、大企業経営者
   - 居住高度: 300-500m
   - 特権: 最高の生活環境、政治的影響力

2. **上層民（じょうそうみん）** - 上層部居住者
   - 人口比: 約15%
   - 特徴: 富裕層、知識人、専門職
   - 居住高度: 200-300m
   - 特権: 良好な教育、安定した生活

3. **中層民（ちゅうそうみん）** - 中層部居住者
   - 人口比: 約40%
   - 特徴: 中流階級、商人、職人
   - 居住高度: 100-200m
   - 生活: 標準的な生活水準

4. **下層民（かそうみん）** - 下層部居住者
   - 人口比: 約35%
   - 特徴: 労働者階級、工場労働者
   - 居住高度: 50-100m
   - 生活: 苦しい生活、毒ガスへの不安

5. **根無し（ねなし）** - 根元部・樹間移動者
   - 人口比: 約5%
   - 特徴: 極貧層、犯罪者、放浪者
   - 居住: 不定、違法居住
   - 生活: 危険と隣り合わせ

### 社会移動

**上昇移動**:
- 教育による上昇（学園からの奨学金制度）
- 商業的成功
- 政略結婚
- 技術革新や発明
- ただし、実際には困難（既得権益の壁）

**下降移動**:
- 事業の失敗
- 犯罪による追放
- 負債による転落
- 災害や事故

## 政治システム

### 統治形態

各巨大樹は独立した都市国家として機能している。

**ユグドラシル大樹の統治体制** (本作の舞台):

```
         樹主（じゅしゅ）
         最高統治者
              │
    ┌─────────┼─────────┐
    │                          │
  評議会                    執行府
  (立法)                    (行政)
    │                          │
  ├─経済委員会          ├─治安局
  ├─教育委員会          ├─建設局
  ├─防衛委員会          ├─配給局
  └─外交委員会          └─環境局
```

**樹主（じゅしゅ）**:
- 各樹の最高統治者
- 世襲制と選挙制の混在（樹によって異なる）
- ユグドラシルは「選挙君主制」（評議会による選出）
- 任期: 終身（ただし弾劾制度あり）

**評議会**:
- 各階層から選出された代表者で構成
- ただし、上層民の影響力が圧倒的に強い
- 法律の制定、予算の承認

**執行府**:
- 樹主が任命する官僚機構
- 日常的な行政を担当

### 法律と秩序

**主要な法律**:

1. **樹保護法**
   - 樹を傷つける行為の厳罰化
   - 樹の資源の保護

2. **階層移動規制法**
   - 居住階層は許可制
   - 無許可での上層階への立ち入り禁止

3. **地表降下禁止法**
   - 毒ガス層への接近・降下を厳禁
   - 違反者は重罪

4. **資源配分法**
   - 限られた資源の公平な配分を目指す（建前）
   - 実際には階層による格差あり

**治安維持**:
- 樹警察（じゅけいさつ）: 各階層に配置
- スカイガード: 樹の外部と空中交通の警備
- 根元警備隊: 根元部の監視（危険手当が高い）

## 経済システム

### 通貨

**スカイマーク（Sky Mark）**:
- 樹上文明共通の通貨単位
- 略称: SM
- 紙幣と硬貨が流通
- 一部で電子決済も普及

**物価の例**:
- パン1斤: 2 SM
- 学食の定食: 5 SM
- 中層民の月収: 300-500 SM
- 上層民の月収: 1,000-5,000 SM
- 天層民の月収: 10,000 SM以上

### 産業構造

**主要産業**:

1. **農業**
   - 樹上農園での作物栽培
   - 植物工場（人工照明栽培）
   - 収穫量は限定的で貴重

2. **工業**
   - 樹材加工
   - 機械部品製造
   - 飛行船建造
   - 主に下層部で行われる

3. **商業**
   - 樹間交易
   - 市場・商店
   - 中層部が中心

4. **サービス業**
   - 教育
   - 医療
   - 娯楽
   - 上層部に集中

5. **研究開発**
   - 大学・研究所
   - 技術革新
   - 上層部に存在

### 資源と物資

**生産される資源**:
- 食料: 農作物、養殖魚、家畜（限定的）
- 水: 樹が吸い上げる地下水を浄化
- 木材: 樹の自然脱落物、剪定材
- エネルギー: 風力、太陽光、バイオマス

**希少資源**:
- 金属: 旧文明の遺物をリサイクル
- 燃料: 非常に貴重
- 医薬品: 植物由来、限定的
- 布地: 植物繊維、昆虫の糸

**交易**:
- 樹と樹の間で物資を交換
- スカイシップ（飛行船）が主要な輸送手段
- 交易路の確保が経済の生命線

## 教育システム

### 教育制度

**義務教育**:
- 初等教育: 6年間（6-12歳）
- 中等教育: 3年間（12-15歳）
- すべての階層に初等・中等教育の機会あり（建前）
- 実際には下層部の教育環境は劣悪

**高等教育**:
- 学園: 15-18歳（3年間）
- 大学: 18歳以降（4年間）
- 主に上層民・中層民の富裕層が進学
- 奨学金制度あり（狭き門）

### ユグドラシル学園

本作の舞台となる学園。詳細は [ユグドラシル学園](../settings/01-ユグドラシル学園.md) を参照。

- 所在階層: 上層部（250m付近）
- 生徒数: 約1,200名
- 特徴: 全寮制、学術都市として名高い

## 文化と価値観

### 新しい文化

**垂直志向**:
- 「上を目指す」ことが最高の美徳
- 「下に落ちる」ことへの恐怖
- 高い場所＝善、低い場所＝悪という価値観

**樹への敬意**:
- 樹は生命の恩人
- 樹を大切にすることは当然の義務
- 樹の誕生日を祝う「樹誕祭」

**空への憧れ**:
- 自由の象徴としての空
- スカイシップのパイロットは憧れの職業
- 鳥への特別な感情

**地表への禁忌**:
- 地表＝死
- 地表に関する話題はタブー視される傾向
- ただし、若者の間では好奇心も

### 芸術と娯楽

**音楽**:
- 樹の木管楽器が発達
- 樹内部の音響効果を利用したコンサート

**美術**:
- 樹の素材を使った彫刻
- 空や樹を描いた絵画

**文学**:
- 旧文明の物語は伝説化
- 新しい樹上文明の物語

**スポーツ**:
- 垂直競技（樹の外壁を登るクライミング）
- スカイボール（空中で行う球技）
- グライダー競技

**祭り**:
- 樹誕祭: 樹の誕生を祝う祭り
- 収穫祭: 農作物の収穫を感謝する祭り
- 星空祭: 年に一度、樹冠部で星空を見る祭り

---

## 宗教と信仰

### 主要な宗教

1. **樹神教（じゅしんきょう）**
   - 樹を神として崇拝
   - 信者数: 最多
   - 教義: 樹に感謝し、共生する

2. **天空教（てんくうきょう）**
   - 空と天を崇拝
   - 地表は罪の世界、空は救済の場
   - やや厳格な教義

3. **古き教会**
   - 旧文明の宗教を継承
   - 「いつか地表に戻る日」を信じる
   - 少数派

4. **無宗教・世俗派**
   - 科学的世界観
   - 若者に多い

## 技術レベル

### 全体的な技術水準

**旧文明と比較して**:
- 大部分の技術は失われた
- 一部の技術は継承・発展
- 新しい独自技術も開発

**現在の技術**:

```
高度な技術:
- 飛行船技術（旧文明を超える）
- 樹材加工技術
- 垂直建築技術

中程度の技術:
- 電気・通信
- 機械工学
- 医療（基礎レベル）

失われた技術:
- 自動車・鉄道
- 高度な電子機器
- 宇宙開発
- 大規模な化学工業
```

### 交通手段

**樹内交通**:
- エレベーター（人力、蒸気、電動）
- 階段、らせん通路
- ロープウェイ

**樹間交通**:
- スカイシップ（飛行船）: 主要な長距離輸送
- グライダー: 短距離移動
- 徒歩連絡橋: 近隣の樹同士を結ぶ

**個人移動**:
- 徒歩が基本
- 富裕層は樹内個人エレベーター
- 一部でセグウェイ的な乗り物

## 情報と通信

### 通信技術

- 有線通信: 樹内に敷設された通信網
- 無線通信: 限定的（技術レベルの制約）
- 樹間通信: 光信号、無線中継

### メディア

- 新聞: 主要な情報源
- ラジオ: 普及している
- テレビ: 一部の富裕層のみ
- インターネット: 初期的なネットワークが存在

## 軍事と防衛

### 脅威

**外部からの脅威**:
- 他の樹との紛争（稀）
- 空賊（スカイパイレーツ）: スカイシップを襲う
- 野生動物（大型の鳥類など）

**内部の脅威**:
- 犯罪組織
- 階層間の対立
- テロリズム

### 防衛組織

**スカイガード**:
- 樹の防衛組織
- 飛行船部隊を保有
- 空賊の討伐、警戒

**樹警察**:
- 治安維持
- 犯罪捜査

**市民防衛隊**:
- 自警団的組織
- 各階層に存在

---

## 医療と福祉

### 医療制度

- 公立病院: 各階層に存在（質は階層により大差）
- 私立病院: 上層部、高額
- 診療所: 中下層に点在

### 主な疾病

- 呼吸器疾患: 下層部で多い（毒ガスの微量暴露）
- 栄養失調: 貧困層
- 高所病: 稀だが、急激な階層移動で発症
- 感染症: 人口密集地で流行

### 福祉

- 公的扶助: 最低限の食料配給
- 孤児院: 各樹に存在
- 高齢者施設: 不足気味

---

## 物語における重要性

この社会システムは、登場人物たちの生活、価値観、行動を規定する。主人公たちは上層民として恵まれた環境にいるが、階層社会の矛盾や不公平に疑問を抱き始める。

下層部の現実、根元部の謎、他の樹との関係、そして「地表に何があるのか」という禁断の問いが、物語の重要なテーマとなる。
